🛍️ Customer Behavior Analysis
A multi-tool data analysis project exploring customer shopping patterns, spending habits, and segmentation insights using SQL, Python, and Power BI.
---
📁 Project Structure
```
Customer-Behavior-Analysis/
│
├── customer_shopping_behavior.csv       # Raw dataset (3,900 records)
├── customer_behavior_analysis.ipynb     # Python EDA & visualizations
├── Customer Behavior.sql                # SQL business queries
└── customer_shopping_behavior.powerbi.pbix  # Power BI dashboard
```
---
📊 Dataset
The dataset contains 3,900 customer transaction records with the following key attributes:
Column	Description
`customer_id`	Unique customer identifier
`age` / `age_group`	Customer age and age bracket
`gender`	Male / Female
`item_purchased`	Product name
`category`	Product category
`purchase_amount`	Transaction value (USD)
`review_rating`	Customer rating (1–5)
`subscription_status`	Subscribed or not
`shipping_type`	Standard, Express, etc.
`discount_applied`	Yes / No
`previous_purchases`	Number of past purchases
---
🔍 Key Business Questions Answered
SQL Analysis
What is the total revenue generated by male vs. female customers?
Which customers used a discount but still spent above the average purchase amount?
Which are the top 5 products with the highest average review rating?
How does average spend compare between Standard and Express shipping?
Do subscribed customers spend more than non-subscribers?
Which 5 products have the highest discount application rate?
How are customers segmented into New, Returning, and Loyal groups?
What are the top 3 most purchased products within each category?
Are repeat buyers (>5 purchases) more likely to subscribe?
What is the revenue contribution of each age group?
---
💡 Key Findings
Subscribed customers generate higher average spend and total revenue compared to non-subscribers
Loyal customers (more than 10 previous purchases) make up a significant portion of total revenue
A subset of customers who applied discounts still spent above the average purchase amount, indicating strong purchase intent
Express shipping users tend to have a higher average purchase amount than Standard shipping users
Certain product categories consistently dominate the top purchases across all segments

🚀 How to Run
Python Notebook
Clone the repository:
```bash
   git clone https://github.com/shoaibcore/Customer-Behavior-Analysis.git
   ```
Install dependencies:
```bash
   pip install pandas matplotlib seaborn jupyter
   ```
Launch the notebook:
```bash
   jupyter notebook customer_behavior_analysis.ipynb
   ```
SQL Queries
Load `customer_shopping_behavior.csv` into a PostgreSQL database as a table named `customer`
Run queries from `Customer Behavior.sql` in your SQL client (pgAdmin, DBeaver, etc.)
Power BI Dashboard
Open `customer_shopping_behavior.powerbi.pbix` in Power BI Desktop
Refresh the data source if prompted
